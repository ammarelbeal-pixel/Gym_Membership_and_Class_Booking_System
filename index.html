System Analysis Report

This report summarizes the project scenario and the intended requirements for the Gym Membership & Class Booking System.

1. Current State of the System

Based on the project scenario and sample answers, membership details are recorded in spreadsheets, while class bookings are checked electronically through the gym’s web page. Some tasks may still involve manual recording. Staff may spend extra time tracking membership expiry dates, payment status, and class availability. These separate steps can make it harder to prevent booking conflicts and keep records accurate.

2. System Goals

The proposed system should keep member profiles, membership plans, payment details, and renewal dates in one place. It should let members view class schedules and available places, book or cancel classes, and receive useful reminders. Staff should manage schedules and attendance, update membership status, and generate reports while reducing manual work and booking errors.

3. Interviewee Opinions

The sample responses suggest that users expect faster membership management, fewer booking mistakes, easier access to payment and expiry information, and better service. Trainers may benefit from accurate attendance lists, while managers may value reports about membership activity and class demand.

4. Interviewee Feelings

The sample interviewee feels positive because the system may make daily tasks easier. The closed-ended response indicates that the interviewee is not concerned about learning to use it, although clear instructions would still be helpful. Other users may feel differently, so their feedback should be collected before implementation.

Conclusion: The system should centralize membership and payment information, simplify class booking and cancellation, keep class availability accurate, and provide useful reports. A clear interface and suitable instructions can help staff and members adopt the system.

Note: This is a sample project report based on the supplied project scenario and example answers, not verified results from real interviews.
