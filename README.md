Planning Phase Overview

 1. Project Description
A web/database system designed to manage gym operations, member subscriptions, trainer schedules, and class bookings efficiently.

 2. System Request
Problem: Manual tracking of memberships and class bookings causes delays and administrative errors.
Objective: Automate gym operations, streamline member registrations, and manage class schedules through a centralized database.

 3. Feasibility Study
Technical Feasibility: The team possesses the required database and analysis tools to successfully implement the system.
Economic Feasibility: Eliminates paper waste, reduces human errors, and improves overall operational efficiency.
